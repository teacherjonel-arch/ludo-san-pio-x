# Ludo Matemático — 5.º A Olivos

Juego de Ludo educativo en línea para 2, 3 o 4 jugadores.

## Preguntas
- Álgebra: 6 problemas.
- Aritmética: 6 problemas.
- Geometría: 6 problemas.
- Trigonometría: 6 problemas.
- Habilidad Matemática: 4 problemas y se selecciona uno al azar.

Los problemas previamente editados se conservan.

## Render
Build Command: `npm install`
Start Command: `node server.js`
